✦ Misc tools

Current time and date: Add a variable, select a button, then go to Actions → When clicked → Set variable to current time/date.

Random numbers: Use Actions → Set variable to a random number.

Show values in text: Write Time: {clock} or Score: {score} in any text box.

Move using variables: Use Actions → Set position from variables.
